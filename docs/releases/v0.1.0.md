## Content

- Voice-guided interviews with local transcription, review and confirmation.
- AI tutor with one follow-up per question, evaluation with excerpts, explained
  corrections and rewrite per question; final report reusing existing
  evaluations.
- Practice: B1/B2/C1 rewrite, suggestion voice, comparison and stories.
- OpenCode Go (`deepseek-v4.1-flash`, `/inference/go/openai/v1`), own identity,
  stable session and one-time adaptation of the old configuration.
- Local diagnostics with export, without interview content.
- Updated interface with audio recovery.

Functional and integration detail in [OpenCode Go](../opencode-go/validation.md),
[per-question evaluation](../ai-coaching/validation.md) and
[diagnostics](../diagnostics/validation.md).

## Limitations and pending items

- The **installer was not installed** on this machine: packaged installation,
  upgrade over a previous version and uninstallation remain to be validated.
- Phases 1 to 4 have no recorded manual acceptance; real audio, microphone,
  Kokoro voice and semantic usefulness remain pending.
- The acceptance of tutor requests in the Go modality and the real costs are not
  confirmed; no paid request was made in the preparation.
- Local mode requires Python 3.11, the `audio-worker` helper and the Whisper
  `small`/Kokoro-82M models prepared outside the repository
  (see [phase 1 setup](../phase-1/setup.md)). The release does not include them.
- The textual evaluation is not a diagnosis of pronunciation, fluency or
  confidence.

this first run. In a following release, raise the version in
`src-tauri/tauri.conf.json` before building: the artifact names include the
number and would be generated again with the same name.
